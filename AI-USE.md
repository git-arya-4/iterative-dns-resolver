## 3. Explicit Non-Generation Confirmation

The following core DNS protocol components **WERE NOT GENERATED BY AI** and will be implemented manually by team members per assignment rules:

- ❌ RFC 1035 wire packet encoder (`src/idns/wire/`)
- ❌ RFC 1035 wire packet decoder (`src/idns/wire/`)
- ❌ DNS domain name compression algorithm (`0xC0` pointer parsing & generation)
- ❌ Low-level UDP socket transport layer & retry algorithm (`src/idns/transport/`)
- ❌ Root -> TLD -> Authoritative referral step algorithm (`src/idns/iterative/`)
- ❌ Glue record resolution and nameserver bootstrapping (`src/idns/iterative/`)
- ❌ TTL cache eviction engine (`src/idns/cache/`)
- ❌ RFC 2308 negative caching algorithm (NXDOMAIN & NODATA) (`src/idns/cache/`)
- ❌ CNAME chain resolver algorithm (`src/idns/core/`)
- ❌ Local DNS server port 53 socket listener loop (`src/idns/server/`)
